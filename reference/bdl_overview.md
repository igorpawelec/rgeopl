# The State Forests at a glance

One row per regional directorate: how many inspectorates and forest
ranges it runs, and the span of BDL edition stamps found among them.
That span is currently a single year everywhere (2026); it is reported
as a range so that an unevenly stamped future release would show up
rather than hide.

## Usage

``` r
bdl_overview()
```

## Value

A data frame, one row per regional directorate, with a total row.

## See also

\[bdl_catalogue()\] for the underlying listing.

## Examples

``` r
if (FALSE) { # \dontrun{
bdl_overview()
} # }
```
